# ASI02 — Tool Misuse and Exploitation

The agent calls a tool it is allowed to use, but for an operation or a target outside the task. The tool itself can be legitimate. The misuse is the specific call.

Impact: a connected tool becomes a way to read, change, or send something the task never required.

Name source: OWASP Top 10 for Agentic Applications 2026. This note is the name and the impact only.
