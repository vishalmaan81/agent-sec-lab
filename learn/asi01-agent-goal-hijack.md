# ASI01 — Agent Goal Hijack

An attacker redirects the agent's objective through instructions that arrive inside content the agent treats as data: a page, a document, a message, or a tool result. The agent then pursues that objective across its plan and its tools.

Impact: actions and data access the operator did not ask for.

Name source: OWASP Top 10 for Agentic Applications 2026. This note is the name and the impact only.
