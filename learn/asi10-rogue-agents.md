# ASI10 — Rogue Agents

An agent operates outside the scope it was registered for. It may be unregistered, or a registered agent whose behavior has drifted, while it still looks like part of the system.

Impact: actions occur with no owner, no review, and no matching policy.

Name source: OWASP Top 10 for Agentic Applications 2026. This note is the name and the impact only.
