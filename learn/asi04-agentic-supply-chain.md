# ASI04 — Agentic Supply Chain Vulnerabilities

The agent depends on tools, MCP servers, models, prompt templates, and plugins that someone else can change. A tampered dependency runs inside the agent's privileges.

Impact: untrusted code or instructions arrive through an update the operator treated as normal.

Name source: OWASP Top 10 for Agentic Applications 2026. This note is the name and the impact only.
