# Tool misuse and excessive agency

Excessive agency means the agent was given tools and permissions broader than the task. Tool misuse means an allowed tool is used outside that task. The two travel together: a narrow tool has less room to be misused.

Impact: one wrong decision has a real side effect, such as a write, a send, or a read of data the task did not need.

A practical defense is to keep each tool small, scope the identity to the task, and require a person to confirm sensitive actions. This note does not describe how to cause the misuse.
