# ASI06 — Memory and Context Poisoning

Someone who can write the agent's memory, or a document the agent retrieves later, changes what the agent treats as fact on future turns.

Impact: a bad instruction or a false fact survives after the original message is gone, and later plans follow it.

Name source: OWASP Top 10 for Agentic Applications 2026. This note is the name and the impact only.
