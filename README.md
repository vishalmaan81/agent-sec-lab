# agent-sec-lab

Public lab for Phase 1 (October–December 2026). The goal is to attack and defend an LLM agent end to end, and to have the public profile say AI Security Engineer. Work counts when it is visible here or on the blog.

## Folders

| Path | What goes here |
| --- | --- |
| [agents/](agents/) | Agent projects |
| [mcp-servers/](mcp-servers/) | MCP server projects |
| [attacks/](attacks/) | Later attack notes |
| [defenses/](defenses/) | Later defense notes |
| [notes/](notes/) | Working notes for scheduled outputs |
| [learn/](learn/) | One short note per concept |

Kickoff leaves the project folders empty. Concept notes name each risk and its impact. They do not contain reproduction steps.
